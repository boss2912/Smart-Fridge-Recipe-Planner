# frontend/ — หน้าเว็บ

> ⬜ **ยังไม่เริ่ม** — เริ่มพร้อมขั้น 2 ([ADR-008](../docs/DECISIONS.md#adr-008--ทำเป็นเว็บแอปที่ใช้งานได้จริง)) · เป็นงานเพิ่มนอกงานส่ง 4 ชิ้นของอาจารย์ (Lecture 1 หน้า 11)

## หน้าที่

หน้าเว็บที่ผู้ใช้ทั้ง 2 กลุ่มเปิดผ่านเบราว์เซอร์ [`nginx/`](../nginx/) เป็นตัวส่งไฟล์หน้าเว็บให้ และหน้าเว็บเรียก API ของ [`backend/`](../backend/) ผ่าน `/api/`
