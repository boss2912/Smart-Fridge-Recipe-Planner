## หน้าที่

หน้าเว็บที่ผู้ใช้ทั้ง 2 กลุ่มเปิดผ่านเบราว์เซอร์ เขียนเป็น template HTML + CSS ที่ Flask ใน [`backend/`](../backend/) เติมข้อมูลแล้วส่งผ่าน [`nginx/`](../nginx/) · ใช้ JavaScript เฉพาะที่จำเป็น ([ADR-009](../docs/DECISIONS.md#adr-009--เลือกภาษาและวิธีรันเว็บแอป))
