## หน้าที่

เก็บงานขั้นที่ 3 ตาม Key Deliverables (Lecture 1 หน้า 11) คือ **SQL Implementation Script**

## แบ่งโฟลเดอร์แบบนี้

```text
database/
├── schema/    DDL สร้างตาราง + constraint
├── seeds/     ข้อมูลตัวอย่าง
└── queries/   query ที่ระบบต้องทำ ไฟล์ละเรื่อง พร้อมคำอธิบาย
```

## query ที่ต้องมี

| เรื่อง | กฎที่ต้องทำให้ได้ |
|---|---|
| เตือนของใกล้หมดอายุ | นับเฉพาะล็อตบ้านตัวเองที่ยังเหลือของ · แสดงจำนวนวันที่เหลือแบบนับถอยหลัง · "ใกล้" คือเหลืออีกไม่เกิน 3 วัน · ที่หมดอายุแล้วแยกหัวข้อ "หมดอายุแล้ว" · ล็อตไม่มีวันหมดอายุไม่เตือน |
| แนะนำเมนูที่ทำได้ | นับเฉพาะล็อตบ้านตัวเองที่ยังเหลือและยังไม่หมดอายุ · วัตถุดิบที่ไม่ใช่เครื่องปรุงต้องพอ · เครื่องปรุงไม่พอยังขึ้น พร้อมป้าย "เครื่องปรุงไม่พอ" ([ADR-014](../docs/DECISIONS.md#adr-014--เครื่องปรุงลงตู้เป็นล็อต-เลือกเพิ่มตอนทำอาหาร)) |
| ทำอาหาร | นับและหักเฉพาะล็อตบ้านตัวเองที่ยังไม่หมดอายุ · ปริมาณ × จำนวนเท่า ([ADR-017](../docs/DECISIONS.md#adr-017--ทำอาหารเลือกได้ว่าทำกี่เท่าของสูตร)) · เช็คของขาดก่อน (ยกเว้นเครื่องปรุง หักเท่าที่มี) → บันทึกประวัติ → หักล็อตที่หมดอายุเร็วที่สุดก่อน ทั้งหมดในธุรกรรมเดียว ([ADR-001](../docs/DECISIONS.md#adr-001--ทำอาหารแล้วระบบหักวัตถุดิบตามสูตร)) |
| ทิ้งของ | บันทึกประวัติ → หักจากล็อตนั้น ในธุรกรรมเดียว · ทิ้งเกินที่มีไม่ได้ · ทิ้งของบ้านอื่นไม่ได้ ([ADR-003](../docs/DECISIONS.md#adr-003--ต้องมีการบันทึกการทิ้งของ)) |
| ดูประวัติ | ประวัติการทำอาหาร (หักล็อตไหนไปเท่าไร [ADR-012](../docs/DECISIONS.md#adr-012--เก็บว่าทำอาหารแต่ละครั้งหักล็อตไหนไปเท่าไร)) และประวัติการทิ้งของ เฉพาะบ้านตัวเอง |
| แก้บันทึกผิด | ยกเลิกการทำอาหารหรือการทิ้ง คืนของเข้าล็อตเดิม ในธุรกรรมเดียว |
| สรุปผล | ยอดทิ้งต่อบ้าน · เมนูที่ทำบ่อย · dashboard ผู้ดูแลระบบ: เติมล็อตวันไหนของสัปดาห์ · ทำอาหารกี่ครั้งต่อสัปดาห์ ใช้ JOIN + GROUP BY (Phase 2 Advanced Queries & Join) ([ADR-015](../docs/DECISIONS.md#adr-015--ผู้ดูแลระบบดูได้ทุกบ้านและปิดบัญชีบ้านได้)) |

## กรณีทดสอบ

ข้อมูลตัวอย่างใน `seeds/` ต้องมีครบ 4 กรณีนี้ และแต่ละกรณีเขียนไว้ว่าผลที่ถูกต้องคืออะไร

| กรณี | ผลที่ถูกต้อง |
|---|---|
| ของไม่พอทำเมนู | ไม่แนะนำเมนูนั้น · กดทำอาหารแล้วไม่บันทึกอะไรเลย ล็อตไม่ถูกหัก |
| ล็อตหมดอายุ | ไม่นับตอนแนะนำเมนูและไม่ถูกหักตอนทำอาหาร แต่ยังทิ้งได้ |
| ล็อตของบ้านอื่น | ไม่นับ ไม่หัก ไม่เตือน และทิ้งไม่ได้ |
| เครื่องปรุงไม่พอ | เมนูขึ้นพร้อมป้าย "เครื่องปรุงไม่พอ" · กดทำอาหารได้ หักเครื่องปรุงเท่าที่มี |

เดโมวันนำเสนอใช้ 2 เครื่อง (เครื่อง 1 Nginx · เครื่อง 2 Flask + PostgreSQL [ADR-009](../docs/DECISIONS.md#adr-009--เลือกภาษาและวิธีรันเว็บแอป))
