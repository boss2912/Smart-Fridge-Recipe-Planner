# database/ — SQL Implementation Script

👤 SQL สร้างตาราง + ข้อมูลตัวอย่าง: เจตน์ · SQL query ตามกฎของระบบ: ภูมิ · แบงค์ · บอส · ภีม — ดู [`../docs/TEAM_AND_WORKFLOW.md`](../docs/TEAM_AND_WORKFLOW.md)

> ⬜ **ขั้น 3 ยังไม่เริ่ม** — เริ่มรอบที่ 5 (16 ธ.ค.) หลัง Relational Schema เสร็จ · DBMS คือ **PostgreSQL** ([ADR-005](../docs/DECISIONS.md#adr-005--เลือก-dbms))

## หน้าที่

เก็บงานขั้นที่ 3 ตาม Key Deliverables (Lecture 1 หน้า 11) คือ **SQL Implementation Script**

## แบ่งโฟลเดอร์แบบนี้

```text
database/
├── schema/    DDL สร้างตาราง + constraint
├── seeds/     ข้อมูลตัวอย่าง
└── queries/   query ที่ระบบต้องทำ ไฟล์ละเรื่อง พร้อมคำอธิบาย
```

## query ที่ต้องมี

| เรื่อง | กฎที่ต้องทำให้ได้ |
|---|---|
| เตือนของใกล้หมดอายุ | นับเฉพาะล็อตบ้านตัวเองที่ยังเหลือของ · แสดงจำนวนวันที่เหลือแบบนับถอยหลัง · "ใกล้" คือเหลืออีกไม่เกิน 3 วัน |
| แนะนำเมนูที่ทำได้ | นับเฉพาะล็อตบ้านตัวเองที่ยังเหลือและยังไม่หมดอายุ · วัตถุดิบทุกอย่างในสูตรต้องพอ |
| ทำอาหาร | นับและหักเฉพาะล็อตบ้านตัวเองที่ยังไม่หมดอายุ · เช็คของขาดก่อน → บันทึกประวัติ → หักล็อตที่หมดอายุเร็วที่สุดก่อน ทั้งหมดในธุรกรรมเดียว ([ADR-001](../docs/DECISIONS.md#adr-001--ทำอาหารแล้วระบบหักวัตถุดิบตามสูตร)) |
| ทิ้งของ | บันทึกประวัติ → หักจากล็อตนั้น ในธุรกรรมเดียว · ทิ้งเกินที่มีไม่ได้ · ทิ้งของบ้านอื่นไม่ได้ ([ADR-003](../docs/DECISIONS.md#adr-003--ต้องมีการบันทึกการทิ้งของ)) |
| ดูประวัติ | ประวัติการทำอาหาร (หักล็อตไหนไปเท่าไร [ADR-012](../docs/DECISIONS.md#adr-012--เก็บว่าทำอาหารแต่ละครั้งหักล็อตไหนไปเท่าไร)) และประวัติการทิ้งของ เฉพาะบ้านตัวเอง |
| สรุปผล | ยอดทิ้งต่อบ้าน · เมนูที่ทำบ่อย ใช้ JOIN + GROUP BY (Phase 2 Advanced Queries & Join) |

## กรณีทดสอบ

ข้อมูลตัวอย่างใน `seeds/` ต้องมีครบ 3 กรณีนี้ และแต่ละกรณีเขียนไว้ว่าผลที่ถูกต้องคืออะไร

| กรณี | ผลที่ถูกต้อง |
|---|---|
| ของไม่พอทำเมนู | ไม่แนะนำเมนูนั้น · กดทำอาหารแล้วไม่บันทึกอะไรเลย ล็อตไม่ถูกหัก |
| ล็อตหมดอายุ | ไม่นับตอนแนะนำเมนูและไม่ถูกหักตอนทำอาหาร แต่ยังทิ้งได้ |
| ล็อตของบ้านอื่น | ไม่นับ ไม่หัก ไม่เตือน และทิ้งไม่ได้ |

เดโมวันนำเสนอใช้ 2 เครื่อง (database กับเว็บอยู่คนละเครื่อง [ADR-009](../docs/DECISIONS.md#adr-009--เลือกภาษาและวิธีรันเว็บแอป))
